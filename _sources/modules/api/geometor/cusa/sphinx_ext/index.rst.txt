.. py:function:: register_latin_track(book_mod: types.ModuleType | object | None = None) -> bool

   Register and label the ``la`` companion track on ``photon_platform.publish.book``.

   Ensures that ``<slug>-la.rst`` tracks appear immediately after ``en`` with the
   canonical tab label ``"Latin"``.

   :param book_mod: Optional pre-imported ``photon_platform.publish.book`` module (or mock
                    object in unit tests). When ``None``, imports it dynamically.

   :returns: ``True`` if ``photon_platform.publish.book`` is available and patched, ``False``
             otherwise.
